# LEFTY project memory

Significant decisions and reviews belong under the appropriate area: `project/`, `decisions/`, `architecture/`, `ux-research/`, `algorithms/`, `engineering/`, `testing/`, `user-testing/`, `demos/`, and `approvals/`.

Every record includes: **ID, date, agent, context, problem, decision, reason, evidence, result, status, and related artefacts**. Statements not verified by evidence must be labelled as assumptions.
